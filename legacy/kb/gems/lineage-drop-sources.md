# Lineage supports — drop sources and effects (0.5.x)

Status: done for 0.5.x (77 lineage-tagged gems; 11 have no source shown). Companion to [[gems/lineage-supports]] (rules, full list, prices). Batch 29, verified by inspection 2026-11-26 (18/18 claims).

Version: 0.5.x data (PoE2DB crawl 2026-11-23). Not checked against 1.0.
Sources: [PoE2DB Lineage Supports](https://poe2db.tw/us/Lineage_Supports) and each gem's own PoE2DB page (e.g. [Uhtred's Exodus](https://poe2db.tw/us/Uhtreds_Exodus)), tier 2, crawl 2026-11-23.

## Lineage page intro text
- Claim: PoE2DB describes Lineage supports as powerful support gems that can drop in maps or come from a specific source such as a boss. Only one copy of a given lineage support may be socketed across all skills at once.
- Version: 0.5.x
- Volatility: may-change
- Source: [PoE2DB Lineage Supports](https://poe2db.tw/us/Lineage_Supports), tier 2, crawl 2026-11-23
- Confidence: single-source
- Notes: Existing doc already has one-copy rule. "Global" in the table below is PoE2DB's label for gems with no named source; the page does not define it. [INFERRED]: it means the general map drop pool, because the page intro says lineage supports "can drop in maps".

## Tier / requirements shared by almost all lineage supports
- Claim: Nearly every lineage support requires character level 65, has gem drop level 52, and a +5 attribute requirement (Str, Dex or Int depending on gem). The exceptions are the three Large Abyssal Trove gems (Kurgal's Leash, Kulemak's Dominion, Amanamu's Tithe): requires level 25, drop level 20, +5 Str or Int. Each has a single gem level (Level Effect /1); Mórrigan's Insight page shows /40.
- Version: 0.5.x
- Volatility: may-change
- Source: [PoE2DB Kurgal's Leash](https://poe2db.tw/us/Kurgals_Leash), [PoE2DB Uhtred's Exodus](https://poe2db.tw/us/Uhtreds_Exodus), tier 2, crawl 2026-11-23
- Confidence: single-source (pattern read from ~75 gem pages)
- Notes: Newer 0.5.0 gems (Her Declaration, Seraph's Heart etc.) have no attribute line on their pages; some show "Additional Reservation: 30 or 45 Spirit" (Her Declaration 30, Arbiter's Reach 30, Tangmazu's Thurible 30, Seraph's Heart 45). Cost multipliers where shown: 90%-130% (see table). Full 1-socket-level data, no per-level scaling.
