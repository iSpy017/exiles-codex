# Attack, Cast & Skill Speed

Status: partial — no worked formulas yet (dual wield, weapon base rates). Re-check at 1.0.
Access note: poe2wiki claims come from search-engine snippets (direct fetch blocked).

## Attacks use the weapon; spells use the skill
- Claim: An attack's base damage, attack speed and crit come from the equipped weapon unless the skill says otherwise. Spells have their own base damage, cast time and crit, and ignore weapon stats.
- Version: 0.5.x
- Volatility: stable
- Source: [poe2wiki Attack](https://www.poe2wiki.net/wiki/Attack), tier 2; [PoE2DB Keywords](https://poe2db.tw/us/Keywords), tier 2; retrieved 2026-11-17
- Confidence: confirmed

## Skill speed stacks additively with attack/cast speed
- Claim: "Skill Speed" affects every skill and adds together with attack speed, cast speed, warcry speed and similar stats into one total. E.g. 6% increased cast speed + 5% increased skill speed = 11% for spells.
- Version: 0.5.x
- Volatility: may-change
- Source: [poe2wiki Skill speed](https://poe2wiki.net/wiki/Attack_speed), tier 2; [Mobalytics Skill Speed](https://mobalytics.gg/poe-2/guides/skill-speed), tier 3; retrieved 2026-11-17
- Confidence: confirmed

## Action speed is different
- Claim: Action Speed is a separate, rarer stat calculated differently from skill speed (not additive with it).
- Version: 0.5.x
- Volatility: may-change
- Source: [Mobalytics — Skill Speed explained](https://mobalytics.gg/poe-2/profile/dreamcore/guides/poe-2-skill-speed-explained), tier 3, retrieved 2026-11-17
- Confidence: single-source
- Notes: [INFERRED] multiplicative like PoE1's action speed; the PoE2 page doesn't state it in what we saw.

## Fixed use-time penalties can't be sped up
- Claim: Some skills carry a flat time penalty (e.g. "+X seconds to Total Attack Time"). It's added after speed modifiers, so speed stats don't reduce it.
- Version: 0.5.x
- Volatility: may-change
- Source: [poe2wiki Skill speed](https://www.poe2wiki.net/wiki/Cast_speed), tier 2, retrieved 2026-11-17
- Confidence: single-source
